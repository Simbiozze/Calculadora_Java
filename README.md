Este projeto consiste no desenvolvimento de uma calculadora simples utilizando a linguagem Java.

A aplicação tem como objetivo implementar funcionalidades de uma calculadora, colocando em prática conceitos fundamentais de programação, lógica computacional e desenvolvimento de software orientado a objetos.

O projeto está em desenvolvimento e representa uma oportunidade de aprimorar conhecimentos na linguagem Java, explorar operações matemáticas e evoluir a implementação de funcionalidades.

⚙️ Funcionalidades
O projeto tem como proposta o desenvolvimento de uma calculadora para realizar operações matemáticas.

🧮 Implementação de uma calculadora em Java.
🔢 Processamento de operações matemáticas.
💻 Desenvolvimento da lógica de funcionamento da aplicação.
Status: algumas funcionalidades ainda estão em desenvolvimento.
